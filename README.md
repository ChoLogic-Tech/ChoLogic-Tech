I am a passionate coder returning to programming as a hobby! Back in the day, I built projects using native, standard PHP. Now, I am diving back in to master modern object-oriented PHP and explore powerful full-stack frameworks. 

### My Return Project: AssetPulse 🚀

- **[AssetPulse](https://github.com/ChoLogic-Tech/AssetPulse):** A web-based Multi-Property Inventory & Asset Tracking System built with React, Inertia, Laravel, and the Tailwind CSS framework. I use React and Tailwind CSS for the interactive user interface on the frontend, Inertia for handling routing between Laravel and React pages, Laravel for managing backend configurations, and lastly, PostgreSQL for the database.

### 🛠️ Current Tech Stack & Tools
